# МедАнализ

Android-приложение для разбора медицинских документов с помощью Claude (Anthropic).
Внутри зашит медицинский мастер-промпт (`app/src/main/assets/system_prompt.md`):
документы загружаются пакетами, после фразы «ВСЕ ФАЙЛЫ ЗАГРУЖЕНЫ» ИИ задаёт вопросы
и даёт итоговый анализ.

> Приложение не ставит диагноз и не заменяет врача. При опасных симптомах звоните 103 или 112.

## Как установить на телефон

1. Откройте на телефоне страницу **Releases** этого репозитория
   (справа на главной странице GitHub или `…/medical-assistant/releases`).
2. В самом свежем релизе скачайте файл `MedAnaliz-1.0.N.apk`.
3. Откройте скачанный файл. Android спросит разрешение «Установка из неизвестных источников»
   для браузера: разрешите и вернитесь назад.
4. Нажмите «Установить».

Новые версии ставятся поверх старой, переписка сохраняется.

## Первый запуск

1. Прочитайте предупреждение и нажмите «Понятно».
2. Получите ключ API: [console.anthropic.com](https://console.anthropic.com) → Billing (пополнить баланс)
   → API Keys → Create Key.
3. Вставьте ключ в настройках приложения. Он хранится только на телефоне.

## Как пользоваться

- 📎 прикрепить PDF, фото или текстовые файлы (можно несколько), 📷 сфотографировать документ.
- Отправляйте документы пакетами. После каждого пакета ИИ подтверждает приём.
- Кнопка «✅ Все файлы загружены» отправляет фразу «ВСЕ ФАЙЛЫ ЗАГРУЖЕНЫ».
- ➕ начать новый разбор, ☰ история разборов, ⚙ настройки.

## Как изменить промпт

Отредактируйте `app/src/main/assets/system_prompt.md` прямо на GitHub и сохраните (Commit).
GitHub сам соберёт новую версию APK в Releases примерно за 5–10 минут.

## Устройство

- `core/` — общая логика: модели данных и работа с Claude API (SDK `anthropic-java`),
  модель `claude-opus-5-5`, файлы отправляются через Files API, история кэшируется.
- `app/` — приложение Android (Kotlin, Jetpack Compose).
- `.github/workflows/build.yml` — сборка APK и публикация релиза при каждом изменении `main`.
